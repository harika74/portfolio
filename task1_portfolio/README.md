# Developer Field Notes — Portfolio

A responsive personal portfolio built with semantic HTML, CSS, and vanilla JavaScript. No frameworks or build tools required.

## Features
- Responsive layouts for mobile, tablet, and desktop
- Semantic sections and keyboard-accessible navigation
- Mobile navigation toggle
- Light/dark theme toggle
- Project category filters
- CSS-built project artwork (no external project images required)
- Reduced-motion support

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser, or open the folder in VS Code and use the Live Server extension.
3. Edit `index.html` to update the email, LinkedIn, GitHub, and project repository links.

## Before publishing
- Replace `your.email@example.com` with your real professional email.
- Replace all placeholder GitHub URLs (`https://github.com/`) with your actual project repositories.
- Update the LinkedIn URL to your profile.
- Review the project descriptions so they accurately reflect what is implemented.
- Test the site at 375px, 768px, and 1280px or wider.

## Tech stack
HTML5 · CSS3 · Vanilla JavaScript
